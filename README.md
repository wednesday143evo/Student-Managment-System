# Student-Managment-System
Student Management System – Project Description

Developed a Student Management System to efficiently manage student records through a centralized web-based platform. The system allows administrators to perform CRUD operations (Create, Read, Update, Delete) on student data, including personal details, academic information, attendance, and performance records. Implemented a user-friendly interface for easy navigation and secure data management. Integrated a database for storing and retrieving student information efficiently, ensuring data consistency and reliability.

Key Features:

Student Registration and Profile Management
Add, Update, Delete, and Search Student Records
Attendance Management
Marks and Academic Performance Tracking
Secure Login and Authentication
Database Integration for Data Storage
Responsive and User-Friendly Interface

Technologies Used:

Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: SQLite / MySQL
Tools: VS Code, Git, GitHub
